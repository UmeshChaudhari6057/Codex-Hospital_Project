🏥 Hospital Management Microservices

A Complete Microservices Architecture Implementation

📋 Project Overview

This project is a comprehensive Hospital Management System built using microservices architecture. It demonstrates modern Java enterprise application development with Spring Boot, Spring Cloud, and various microservices patterns.

🎯 Purpose

Provide a scalable, maintainable hospital management system with separate services for different business domains.

🏗️ Architecture

Microservices architecture with service discovery, API gateway, and inter-service communication.

🔄 Communication

Both synchronous (OpenFeign) and asynchronous (Kafka) communication patterns.

🔧 Microservices Components

🔍 Discovery Service (Port: 8761)

Eureka Server for service registration and discovery. Acts as the central registry for all microservices.

Eureka Service Registry

🚪 API Gateway (Port: 8080)

Single entry point for all API requests with routing, load balancing, and circuit breaker integration.

Spring Cloud Gateway Load Balancing

👤 User Service (Port: 8081)

User management and authentication with JWT-based security and role-based access control.

JWT Authentication

🤒 Patient Service (Port: 8082)

Patient and insurance management with comprehensive patient data handling.

Patient Data Insurance

👨‍⚕️ Doctor Service (Port: 8083)

Doctor and department management with specialization tracking.

Doctor Management Departments

📅 Appointment Service (Port: 8084)

Appointment booking with inter-service communication and event-driven updates.

Booking Events

Architecture Patterns Implemented

  • Database per Service Pattern - Each microservice has its own database
  • Service Discovery Pattern - Dynamic service registration with Eureka
  • API Gateway Pattern - Single entry point with routing
  • Circuit Breaker Pattern - Fault tolerance with Resilience4j
  • Event-Driven Architecture - Asynchronous messaging with Kafka
  • Saga Pattern - Distributed transaction management

💾 Database Architecture

MySQL Databases

🌐 API Endpoints

Authentication (via User Service)

Method Endpoint Description
POST /api/v1/auth/register Register new user
POST /api/v1/auth/login User login and JWT generation

Patients (via Patient Service)

Method Endpoint Description
POST /api/v1/patients Create new patient
GET /api/v1/patients/{id} Get patient by ID
GET /api/v1/patients/user/{userId} Get patient by User ID

Doctors (via Doctor Service)

Method Endpoint Description
POST /api/v1/doctors Create new doctor
GET /api/v1/doctors Get all doctors
GET /api/v1/doctors/{id} Get doctor by ID

Appointments (via Appointment Service)

Method Endpoint Description
POST /api/v1/appointments Create appointment
GET /api/v1/appointments/{id} Get appointment by ID
PUT /api/v1/appointments/{id}/cancel Cancel appointment
PUT /api/v1/appointments/{id}/complete Complete appointment
